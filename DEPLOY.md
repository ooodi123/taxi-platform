# Запуск на сервере и показ клиентам

Пошагово, от покупки сервера до первого демо таксопарку. Займёт около часа.

## 1. Что купить

| Что | Где | Сколько |
|---|---|---|
| VPS: Ubuntu 24.04, 2 ядра, 4 ГБ памяти, 40 ГБ диска | любой хостинг (Timeweb, Selectel, Hetzner, DigitalOcean…) | ~5–10 $ в месяц |
| Домен | любой регистратор | от ~2 $ в год |

Хватит на несколько таксопарков с сотнями водителей. Растёт нагрузка — берёте сервер побольше, переносить ничего не нужно.

## 2. Направить домен на сервер

У регистратора домена создайте **A-запись**: имя `taxi` (или `@` для корня домена) → IP вашего сервера. Получится, например, `taxi.вашдомен.ru`. Запись начинает работать через 5–30 минут.

## 3. Залить проект и установить

На своём компьютере (вместо `1.2.3.4` — IP сервера):

```bash
scp taxi-platform-stage6.zip root@1.2.3.4:~
ssh root@1.2.3.4
```

На сервере:

```bash
apt-get update && apt-get install -y unzip
unzip taxi-platform-stage6.zip && cd taxi-platform
sudo ./deploy/install.sh
```

Скрипт спросит домен и почту, сам поставит Docker, сгенерирует пароли, запустит всё и получит HTTPS-сертификат. В конце покажет **ключ супер-админа** — он же хранится в файле `.env`.

Проверка: откройте `https://ваш-домен/app/dispatch/` — должна открыться страница входа.

## 4. Демо для показа клиентам

### Подготовка (один раз)

1. Создайте отдельного бота для демо в [@BotFather](https://t.me/BotFather): `/newbot`, имя «Демо Такси», получите токен.
2. На сервере:

```bash
./deploy/demo.sh on                 # демо-таксопарк + виртуальные водители
./deploy/demo.sh bot 123456:ABC...  # подключить демо-бота
```

Город по умолчанию — Москва. Чтобы демо было в вашем городе, перед `demo.sh on` добавьте в `.env`:

```
DEMO_CENTER=47.0105,28.8638
DEMO_TIMEZONE=Europe/Chisinau
DEMO_CURRENCY=MDL
```

(если демо уже создано — поменяйте центр карты в диспетчерской: «Настройки» → «Взять с карты»).

3. В диспетчерской (`demo / demo12345`) зайдите в «Настройки» → «Сотрудники» и смените пароль.

### Как показывать (5 минут)

1. На ноутбуке открыта **диспетчерская**: по карте ездят 5 машин.
2. Даёте клиенту свой телефон или он сам открывает **демо-бота**, нажимает «Заказать такси».
3. Он видит карту, выбирает адрес, видит цены по трём тарифам, нажимает «Заказать».
4. На ноутбуке заказ появляется в ленте, через пару секунд ближайшая машина его принимает.
5. На телефоне: номер машины, водитель, машина едет по карте, бот пишет «Машина найдена», затем «Водитель на месте».
6. Машина «везёт» пассажира, в конце — «Поездка завершена, 420 ₽».
7. Покажите диспетчерскую: историю заказа, ручное назначение, водителей, тарифы, подключение своего бота.

Приложение водителя можно показать на втором телефоне: добавьте себя водителем в демо-таксопарк со своим Telegram ID (узнать его — команда `/driver` в боте). Но учтите: **в демо-режиме всеми водителями демо-таксопарка управляет симулятор**, включая вас. Чтобы показать приложение водителя «вручную», выключите симулятор: `./deploy/demo.sh off`.

## 5. Подключить настоящий таксопарк

```bash
./deploy/new-tenant.sh "Такси Люкс" lux
```

Скрипт выдаст логин и пароль владельца. Дальше владелец таксопарка сам:

1. создаёт своего бота в @BotFather и вставляет токен в «Настройках» диспетчерской;
2. задаёт фирменный цвет, название, центр карты;
3. добавляет водителей (их Telegram ID) и диспетчеров;
4. настраивает тарифы.

Каждый таксопарк видит только свои заказы, водителей и настройки.

## 6. Обслуживание

| Задача | Команда |
|---|---|
| Логи | `docker compose logs -f api` |
| Состояние | `docker compose ps` |
| Обновить платформу | залить новые файлы поверх (кроме `.env` и `backups/`), затем `./deploy/update.sh` |
| Бэкап сейчас | `./deploy/backup-now.sh` |
| Восстановить из бэкапа | `./deploy/restore.sh backups/<файл>.sql.gz` |
| Перезапуск | `docker compose restart api` |

Бэкап базы делается автоматически каждую ночь в папку `backups/`, хранится 14 дней. **Копируйте её куда-то ещё** (другой сервер, облако): если сломается диск сервера, бэкапы на нём пропадут вместе с базой. Например, раз в сутки через `rclone` или `rsync`.

## 7. Когда пойдут реальные заказы

- **Карты.** Публичные тайлы OpenStreetMap не рассчитаны на коммерческую нагрузку. Подключите платный сервис тайлов (MapTiler, Stadia Maps — есть бесплатные лимиты) и пропишите адрес в `webapp/index.html`, `webapp/driver/index.html`, `webapp/dispatch/index.html`: `<script>window.TAXI_TILES = 'https://…/{z}/{x}/{y}.png?key=…'</script>` перед подключением `app.js`.
- **Поиск адресов.** Публичный Nominatim — около 1 запроса в секунду. Под нагрузкой: свой Nominatim/Photon (`GEOCODER_URL`) или платный геокодер.
- **Маршруты.** Сейчас расстояние считается по прямой ×1.35. Для точной цены поднимите OSRM с картой своего региона и укажите `OSRM_URL`.
- **Приложение водителя.** Telegram усыпляет свёрнутые Mini App. Если водители жалуются на пропущенные заказы, следующий шаг — нативное приложение водителя.
- **Законы.** Если вы продаёте софт, а заказы выполняет таксопарк, лицензии и реестры — его ответственность. Обработка персональных данных пассажиров (телефоны, поездки) требует политики конфиденциальности и, в РФ, хранения данных граждан на серверах в России — выбирайте хостинг с учётом этого.
